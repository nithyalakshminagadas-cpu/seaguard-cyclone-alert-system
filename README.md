
# SeaGuard X
### AI-Powered Coastal Intelligence Platform

SeaGuard X is a coastal monitoring and fishermen safety
hackathon prototype.

## Features

- Live weather information
- Marine wave forecast
- Interactive coastal map
- Environmental risk indicator
- Hourly weather forecast
- Current location detection
- Community sea-condition reports
- Responsive dashboard

## Technologies

- HTML5
- CSS3
- JavaScript
- Leaflet.js
- OpenStreetMap
- Open-Meteo Weather API
- Open-Meteo Marine API

## Installation

1. Create a new GitHub repository.
2. Upload all project files.
3. Open repository Settings.
4. Select Pages.
5. Choose Deploy from a branch.
6. Select main branch.
7. Select root folder.
8. Click Save.

## Important

This is a hackathon prototype.

The risk calculation is a demonstration
heuristic, not a validated AI model or
official marine safety prediction.

Community reports are stored locally
in the browser and are not shared
between different users.

Always follow official IMD, INCOIS,
Coast Guard and harbour-authority warnings.
